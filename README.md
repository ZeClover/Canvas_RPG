# Canvas RPG

Este repositório tem **um projeto**: **RPG World Canvas**, dentro da pasta [`rpg-world-canvas/`](rpg-world-canvas/).

Toda a documentação, instruções de instalação (app web e empacotamento desktop Windows) e histórico de fases estão no [`README.md` de dentro dessa pasta](rpg-world-canvas/README.md).

Se você baixou este repositório para rodar ou compilar o app, **entre na pasta `rpg-world-canvas/` primeiro** — é lá que ficam o `package.json`, os scripts `.bat` (`INSTALAR.bat`, `BUILD_WINDOWS.bat`, `ABRIR.bat`, `ABRIR_DEV.bat`) e todo o código.
